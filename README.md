# 曾子昕｜AI & Software Portfolio

此專案為靜態個人作品集，可直接部署至 GitHub Pages。

## 本機預覽

直接以瀏覽器開啟 `index.html`，或使用任一靜態網站伺服器。

## GitHub Pages 部署

1. 建立一個 GitHub repository，將網站檔案推送至 `main` 分支：`index.html`、`styles.css`、`overrides.css`、`script.js`、`awards.js`、`assets/`、`README.md`、`.gitignore` 與 `大頭照新版.JPG`。
2. 進入 repository 的 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**，分支選擇 `main`，資料夾選擇 `/(root)`。
4. 儲存後，GitHub 會提供公開網址。

網站使用新版彩色個人照片 `大頭照新版.JPG`，並將競賽的現場照片與獎狀預覽整理至 `assets/awards/`。原始履歷、證書、簡報與影片已由 `.gitignore` 排除，避免將地址、電話或未經整理的素材公開。
